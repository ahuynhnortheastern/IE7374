# Generative AI for Hospital Performance Communication

## Overview

This project explores how **Generative AI can translate hospital performance data into audience-specific narratives** while preserving the underlying facts.

Hospital performance data is transformed into four communication styles:

* **Patient Friendly**
* **Executive Summary**
* **Clinical**
* **Community Report**

The project evaluates whether prompt engineering can adapt the same healthcare information for different audiences without changing its factual meaning.

## Project Workflow

The notebooks follow an end-to-end pipeline:

`Hospital Data → Data Preparation → Factual Narratives → Generative AI → Evaluation → Application`

Run the notebooks **in numerical order**, as later notebooks depend on files generated by earlier steps.

## How to Run

1. Clone or download this repository.
2. Make sure to download the raw data -- the link is provided in Notebook 1
3. Install the required Python packages.
4. Open the project folder in Jupyter Notebook.
5. Run notebooks **1 through 6 in order**.
6. Use **Notebook 6 — Application** to interact with the completed workflow.

## Data

The project analyzes three hospital performance areas:

* Patient Survey
* Healthcare-Associated Infections
* Timely and Effective Care

## Purpose

The primary question explored is:

> **Can Generative AI communicate the same hospital performance information differently for patients, clinicians, executives, and communities while remaining factually consistent?**
